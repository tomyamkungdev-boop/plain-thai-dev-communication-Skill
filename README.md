# Plain Thai Dev Communication

Skill ที่ช่วยให้ AI ตอบนักพัฒนาเป็นภาษาไทยที่อ่านง่ายและเป็นธรรมชาติ ลดการพูดไทยคำอังกฤษคำ โดยแปลแนวคิดทั่วไปเป็นไทย แต่คงชื่อเฉพาะที่ต้องตรงกับของจริงไว้เป็นภาษาอังกฤษ เช่น คำสั่ง ชื่อไฟล์ ชื่อในโค้ด ชื่อไลบรารี และข้อความแสดงข้อผิดพลาด

## วิธีนำไปใช้งาน

### Claude Code

ดาวน์โหลดโฟลเดอร์นี้ไปไว้ในโฟลเดอร์ skill ของเครื่อง:

```bash
git clone https://github.com/tomyamkungdev-boop/plain-thai-dev-communication-Skill.git ~/.claude/skills/plain-thai-dev-communication
```

ถ้าต้องการใช้เฉพาะโปรเจกต์เดียว ให้วางไว้ที่ `.claude/skills/plain-thai-dev-communication` ในโปรเจกต์นั้นแทน

Claude จะเรียกใช้เองเมื่อคุยกับผู้ใช้ภาษาไทยเรื่องงานพัฒนา หรือเรียกตรง ๆ ด้วยคำสั่ง `/plain-thai-dev-communication`

### Claude (เว็บและแอป)

บีบอัดโฟลเดอร์นี้เป็นไฟล์ `.zip` แล้วอัปโหลดในหน้าตั้งค่า Skills ของ Claude

### Codex

วางโฟลเดอร์นี้ไว้ในโฟลเดอร์ skill ของ Codex (เช่น `~/.codex/skills/`) ไฟล์ `agents/openai.yaml` เป็นข้อมูลชื่อและคำอธิบายที่ Codex ใช้แสดงผล

### Cursor

สร้างไฟล์ `.cursor/rules/plain-thai-dev-communication.mdc` ในโปรเจกต์ แล้วคัดลอกเนื้อหาจาก `SKILL.md` ไปวาง

### ChatGPT และเครื่องมือที่ใส่ได้แค่ข้อความคำสั่ง

ช่อง Custom instructions ของ ChatGPT รับข้อความได้จำกัด (ประมาณ 1,500 ตัวอักษร) ให้คัดลอกเฉพาะหัวข้อ `Core Rules` และ `Wording Rules` จาก `SKILL.md` ไปวาง ถ้าใช้ Projects ของ ChatGPT สามารถวาง `SKILL.md` ทั้งไฟล์ในช่องคำสั่งของโปรเจกต์ได้

หมายเหตุ: การคัดลอกเฉพาะ `SKILL.md` จะทำให้ AI มองไม่เห็นไฟล์ในโฟลเดอร์ `references/` ถ้าเครื่องมือของคุณแนบไฟล์ได้ ให้แนบ `references/glossary.md` และ `references/examples.md` ไปด้วย

## ทำไมถึงควรใช้

- AI มักตอบเป็นไทยปนอังกฤษจนอ่านยาก เช่น "implement", "handle", "validate" ทั้งที่มีคำไทยที่ชัดเจนกว่า skill นี้ให้แปลแนวคิดทั่วไปเป็นไทย
- ในทางกลับกัน ชื่อที่ต้องตรงกับโค้ดจะไม่ถูกแปล จึงคัดลอกไปค้นหาหรือรันต่อได้ทันที
- คำอังกฤษที่จำเป็นต้องใช้และอาจไม่คุ้นเคย จะมีคำอธิบายภาษาไทยสั้น ๆ ในครั้งแรกที่พูดถึง
- คำตอบจัดลำดับเหมาะกับงานพัฒนา เช่น งานเขียนโค้ดจะบอกสิ่งที่เปลี่ยน ไฟล์ที่เกี่ยวข้อง และวิธีตรวจสอบ ส่วนการหาสาเหตุข้อผิดพลาดจะบอกสาเหตุ หลักฐาน และวิธีแก้
